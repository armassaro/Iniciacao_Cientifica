## Descrição da ideia geral do projeto
1. Passar o firmware contendo [[4.4. freeRTOS|freeRTOS]] para o ESP32, a fim de garantir consistência na amostragem do sinal e no envio dos sinais para o computador. Primeiramente, vai ser feita a leitura dos sinais analógicos com o ADC do próprio ESP32
2. Conectar as placas impressas na fresa ao ESP32
3. Verificar como é visto no computador a saída dos dados
4. Pensar sobre como vai ser a feita a trilateração dos dados e como vai ser colocado no código a localização das lâmpadas para referência.
